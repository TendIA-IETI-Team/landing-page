# Field

A visible label, a control styled `td-input` and an optional hint, the portal's `Field` + `inputClass`.

- **Consumer provides:** the label text, the `<input>`, `<select>` or `<textarea>` (class `td-input`), an optional hint.
- Always a visible label, never placeholder-only. Focus: `indigo500` border plus a 2px ring.
- On the landing it appears only in the partner contact form ("Quiero ser aliado").
