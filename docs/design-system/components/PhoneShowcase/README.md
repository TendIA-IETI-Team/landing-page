# PhoneShowcase

Frames that present real product screenshots: `td-phone` for the shopkeeper app (260px, `indigo900` bezel) and `td-browser` for the partner portal (landing addition).

- **Consumer provides:** a screenshot from `assets/Screenshots/` and alt text that says what the screen shows, plus a `td-caption`.
- Only real captures from `docs/img/` in the main repo; never mock a screen. Serve as WebP/AVIF via the framework's image component, with explicit width and height.
