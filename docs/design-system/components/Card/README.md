# Card

A white surface with a `neutral300` hairline and `radius-md` (12px), the portal's `Card` and the system's only container.

- **Consumer provides:** an optional title (`td-card__title` inside `td-card__head`) and action, then children.
- Padding `space-lg` (24px) on the landing; the portal uses 20px in dense views.
- Borders, not shadows: `shadow-sm` is reserved for floating panels. No colored left-border accents.
