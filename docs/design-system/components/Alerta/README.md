# Alerta

An inline message block in one of four tones (`danger`, `warning`, `success`, `info`), from the portal's `Alerta`.

- **Consumer provides:** the message and the tone class `td-alert--<tono>`; `role="alert"` for danger, `role="status"` otherwise.
- On the landing, use `info` once for the "TendIA no presta dinero" disclaimer and `danger`/`success` only for the contact form result.
