# Badge

A pill label for a state or a score band (`Badge`, `EstadoBadge` and `FranjaBadge` in the portal), always carrying a word: color is never the only signal.

- **Consumer provides:** the text and one tone: `td-badge--info | neutral | success | warning | danger | accent`, or a band: `td-badge--bajo | medio | bueno` (Bajo 0–499, Medio 500–649, Bueno 650–1000).
- Bands use the status colors, never the brand orange. When talking to shopkeepers about a low score, say "En construcción".
- `accent` (landing addition) marks something new or an achievement, never a warning.
